# CarboJobs
## Plataforma para conectar prestadores de serviço com seus clientes.

- Idealizado na Hackathon 2022 do IFSul Campus Charqueadas.
- Plataforma para divulgação de Prestadores de Serviço e MEIs da região carbonífera do RS.
- Campeão da competição.
- Desenvolvido em 24 horas durante a competição.
- Selecionado para incubação no Instituto Otélio Drebes em São Jerônimo.
- Apresentei o sistema uma palestra durante o anúncio da South Summit.
- Retomado em 2024, com palestras no projeto Mulheres Mil do IFSul.
